# GitHub naming ideas

Suggestions only; these do not rename the repository or claim name availability.

| Repository name | Display name | Why it fits |
| --- | --- | --- |
| `llmlab` | LLMLab | Matches the app and README; describes its learning labs. |
| `llm-workbench` | LLM Workbench | Emphasizes experiments, real runs, and comparison. |
| `promptscope` | PromptScope | A short name for inspecting prompts and model behavior. |
| `tokenlab` | TokenLab | Highlights tokenization, generation, and learning by doing. |
| `model-lab` | Model Lab | Broad enough for model comparison, RAG, and agents. |
| `llm-explorer` | LLM Explorer | Emphasizes guided exploration for beginners. |

Recommended: **LLMLab** (`llmlab`) for consistency, or **LLM Workbench**
(`llm-workbench`) if you want a more descriptive repository name.
